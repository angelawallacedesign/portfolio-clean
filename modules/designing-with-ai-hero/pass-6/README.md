# Designing with AI Hero — Pass 6

Pass 6 replaces the previous hero copy and workflow with a full-panel, non-interactive motion visual based on the August 23, 2026 AI-assisted design-inspection reference.

The composition pairs a gridded inspection target with an AI-assisted mode summary. A scan crosses the panel while token, state, class, and accessibility annotations pulse in sequence. The plan control and several mode controls receive short staggered press animations, followed by token confirmation. These controls are visual elements only and do not accept pointer input.

The layout fills the complete `.designing-ai-hero__content` container and stacks at the narrow breakpoint. Reduced-motion users receive the complete inspection composition with all looping motion removed.

Open `index.html` for the isolated preview and integration notes. Use `component.html` with the shared global token, local token, component, and module stylesheets.
