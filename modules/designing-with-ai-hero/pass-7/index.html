Designing with AI Hero

Pass 7 abstracts the journey from human thought to working prototype into a five-state motion system: input, thinking, producing, human control, and resolution.

Location

modules/designing-with-ai-hero/pass-7/

Dependencies

  • Required: shared/css/global-tokens.css, css/tokens.css, css/components.css, and designing-ai-hero.css.
  • Global fonts: Inter and DM Serif Display.
  • No JavaScript or animation library is required in Pass 7.

Copy to another compatible project

Copy component.html and designing-ai-hero.css. The compatible host should provide the documented token styles, heading/button primitives, and fonts.

Optional configuration

Edit the semantic content and CTA destination in the component markup. Override module custom properties on an instance to tune stage height, panel insets, extrusion depth, or choreography timing.

Ownership boundary

The host owns global fonts, semantic color tokens, and the shared heading/button primitives. The module owns its stage, background SVG, panel geometry, scoped content layout, choreography, responsive rules, and reduced-motion state. It has no dependency on page selectors or parent layout rules.

Adjust motion

At the top of designing-ai-hero.css, tune the --dai-enter-*, --dai-content-*, and --dai-system-cycle values. Reduced-motion users receive the complete composed workflow state immediately.
