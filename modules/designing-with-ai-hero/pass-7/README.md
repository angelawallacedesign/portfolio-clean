# Designing with AI Hero — Pass 7

Pass 7 turns the journey from thought to working prototype into a full-panel abstract motion system. It uses the August 23 reference for visual density, contrast, geometry, and restraint without reproducing the interface shown in that reference.

The 15-second sequence implements the five-state AWD motion contract: human input condenses into a structured brief; an AI core blinks and applies a shine while thinking; controlled fragments duplicate and travel toward an artifact; motion pauses at a human-control gate; and the accepted result assembles into a stable prototype with an extended resolution hold before looping.

The layout fills the complete `.designing-ai-hero__content` container and reformats into a vertical sequence at the narrow breakpoint. Reduced-motion users receive the resolved composition with all looping motion removed.

Open `index.html` for the isolated preview and integration notes. Use `component.html` with the shared global token, local token, component, and module stylesheets.
