# Angela Wallace — Visual Product Design & Front-End Implementation

This repository contains the ongoing development of my primary portfolio: a full-width, visual-focused implementation built to support deeper project storytelling, interaction, and motion.

The portfolio combines visual product design with front-end implementation. It is intentionally content-dense, allowing case studies and projects to retain the context, process, and design decisions needed to understand the work rather than reducing projects to short presentation frames.

## Portfolio Architecture

Portfolio Clean uses a full-width, continuous page structure designed around visual storytelling and flexible content flow.

The architecture supports:

* Content-dense case studies and project pages
* Full-width and responsive visual layouts
* Reusable navigation and interaction patterns
* Shared design tokens, components, assets, and utilities
* Project-specific presentation where needed
* Motion and interaction as part of the interface system
* Consistent design-to-development implementation

Unlike other portfolio explorations, this version does **not use the Layer 3 presentation system**. Where a similar focused viewing experience is useful, the behavior is scoped locally through a lightbox pattern rather than introducing Layer 3 as a global architectural dependency.

This keeps the portfolio's primary content in the document flow while still supporting immersive presentation for selected visuals.

## Design & Implementation Approach

The portfolio is developed from design intent rather than treating the Figma file and front-end implementation as separate artifacts.

Layout, spacing, typography, copy density, interaction, motion, and responsive behavior are refined together. Reusable patterns are extracted where appropriate while project-specific presentation remains scoped to the content it serves.

Current areas of work include:

* Design-to-code parity
* Motion contracts and implementation
* Copy and layout contracts
* Reusable case-study primitives
* Shared CSS and component governance
* Responsive visual systems
* SVG and asset reuse
* Interaction consistency
* AI-assisted implementation and visual QA

## Philosophy

I’m particularly interested in reducing the distance between **design intent and implementation**.

My approach prioritizes:

* strong visual hierarchy and interface craft
* reusable patterns over repeated one-off solutions
* implementation-aware design decisions
* consistency without sacrificing project expression
* motion and interaction with a defined purpose
* accessible, responsive behavior
* preserving design intent through development

AI is part of that workflow, but not a replacement for design judgment. I use AI-assisted development to accelerate implementation, inspect existing patterns, refactor reusable systems, validate design decisions, and iterate in code while maintaining explicit design, content, and motion constraints.
