# Designing with AI Hero

The portfolio integration keeps the pass 4 hero as a standalone module.

- `pass-4/component.html` contains the reusable hero markup.
- `pass-4/designing-ai-hero.css` owns the module's layout, animation, responsive behavior, and reduced-motion state.
- `pass-4/index.html` and `pass-4/demo.css` provide the isolated preview and integration notes.

The homepage loads `component.html` into the featured-project list. The “View project” control is intentionally a button without a navigation target until its destination is ready.
