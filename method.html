Design Method

I work at the intersection of visual design, design systems, and front-end engineering—translating design intent into functional, production-ready interfaces. I'm especially interested in how AI-assisted workflows can accelerate implementation while preserving visual quality, consistency, and maintainability.

Cross-Functional Alignment I collaborate with designers, product teams, and engineers to establish implementation expectations, identify reusable patterns, and resolve interface behavior before release.

  • Align design intent with technical implementation.
  • Establish reusable components and interaction patterns.
  • Define responsive behavior, states, and edge cases.
  • Reduce drift between design specifications and production code.
  • Validate interface quality before shipping.

INTERFACE

  • I design visual interfaces and interactive experiences, translating layout, behavior, and state requirements into functional UI.

SYSTEMS

  • I build reusable components, design tokens, and motion patterns that maintain consistency across interfaces and implementations.

IMPLEMENTATION

  • I develop and refine front-end interfaces, connecting design decisions to production code with attention to responsiveness, accessibility, and maintainability.
